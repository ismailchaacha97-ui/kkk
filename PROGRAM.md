# MODEL PHYSIQUE - HOME PROGRAM (No BS)
### 12-Week At-Home System for Lean, Aesthetic Muscle

**Goal:** V-taper (wide shoulders/lats, lean chest), visible abs (10-12% BF), athletic legs. No gym needed.

---

## 1. WHAT YOU NEED

**Tier 1 - Ideal (Recommended):**
- Doorway pull-up bar (~$25) - NON-NEGOTIABLE. You can't build a model back/chest without it.
- Adjustable dumbbells up to 20-30kg OR 2x heavy resistance bands + handle
- Backpack you can load with books/water for weighted pushups/squats

**Tier 2 - No Equipment (Calisthenics Only):**
- Pull-up bar still required. If absolutely zero equipment: substitute with towel door rows + backpack, but results will be 30% slower for back.

No bar? Get a suspension trainer or rings to hang from a beam. This is the one investment.

---

## 2. RULES (Do this or it won't work)

1.  **Progressive Overload:** Every week, do MORE than last week. +1 rep, +2kg, +1 set, or slower tempo. Log it. If you're doing the same weight/reps in week 8 as week 1, you failed.
2.  **Tempo:** 2 sec down, 1 sec pause, 1 sec up, 1 sec squeeze. No bouncing. Control builds muscle.
3.  **Rest:** Compound (pushup/row/pullup/squat): 90-120 sec. Isolation (lateral raise/curl): 60 sec. Use a timer.
4.  **Failure:** Last 2 reps should be HARD. Stop 1 rep before form breaks. If you can do 20+ reps easily, add weight (backpack/bands).
5.  **Consistency:** 5-6 days/week. No skipping legs. No skipping pull.
6.  **Diet > Training:** You will NOT see abs at 18%+ body fat, no matter how many crunches. See NUTRITION.md.

---

## 3. THE SPLIT - 6 DAYS / WEEK

You can run this as 5 days if needed (do PPL 1x + Upper/Lower). But 6x is optimal for model look.

| Mon | Tue | Wed | Thu | Fri | Sat | Sun |
|-----|-----|-----|-----|-----|-----|-----|
| PUSH A | PULL A | LEGS A + CORE | PUSH B | PULL B | LEGS B + CONDITIONING | REST + 10k Steps |

Each workout = 45-60 min. Warmup 5 min (jumping jacks, arm circles, band pull-aparts, bodyweight squats)

### PUSH A - Chest / Shoulders / Triceps (Volume)
1. **Standard Pushups** - 4 x 12-20 (if >20, add 10kg backpack) | Rest 90s
   - Hands slightly wider than shoulders, elbows 45°, chest to floor
2. **Pike Pushups** (shoulder focus) - 3 x 8-15 | Rest 90s
   - Progress to: feet elevated pike -> handstand pushup vs wall
3. **Dumbbell/Band Lateral Raises** - 4 x 12-20 | Rest 60s
   - Lean forward slightly, pinky up, control down. #1 for wider shoulders.
4. **Band/Dumbbell Overhead Press** - 3 x 10-15 | Rest 90s
5. **Diamond Pushups / Band Tricep Extension** - 3 x 10-20 | Rest 60s
6. **Plank to Pushup** - 2 x 12 | 60s

### PULL A - Back / Biceps / Rear Delts (Width)
1. **Pull-ups** - 5 x AMRAP (As Many Reps Possible) | Rest 120s
   - Can't do 5? Do negatives: jump up, lower 4 sec. Or band-assisted. Goal: 10+ clean reps.
   - Wide overhand = lats width. Chin-up (palms to you) = biceps.
2. **Inverted Rows (feet on chair, backpack on chest)** - 4 x 10-15 | Rest 90s
   - Body straight, pull chest to bar/table edge.
3. **Resistance Band Face Pulls / Towel Rear Delt Row** - 3 x 15-20 | Rest 60s
   - Crucial for 3D shoulders + posture. Don't skip.
4. **Dumbbell/Band Bicep Curls** - 3 x 12-15 each arm | Rest 60s
5. **Band Lat Pulldown (or backpack pullovers on floor)** - 3 x 12-15 | Rest 90s

### LEGS A + CORE (Athletic, not bulky)
1. **Bulgarian Split Squats (rear foot on couch)** - 4 x 10-12 / leg | Rest 90s
   - Hold dumbbells/backpack. Knee tracks over toes, front thigh parallel.
2. **Romanian Deadlift (dumbbells/backpack)** - 3 x 10-15 | Rest 90s
   - Hamstrings/glutes. Back straight, push hips back.
3. **Jump Squats** - 3 x 15-20 | Rest 60s
4. **CORE CIRCUIT x3 rounds (45s on / 15s off):**
   - Hanging Knee Raises (from pull-up bar) - if no bar: Lying Leg Raises
   - Bicycle Crunches
   - Hollow Body Hold

### PUSH B - Chest / Shoulders / Triceps (Strength)
1. **Weighted Pushups (backpack 10-20kg)** - 5 x 8-12 | Rest 120s
   - Or Archer Pushups if no weight: 3x8/side
2. **Feet-Elevated Pushups** - 3 x 12-15 | Rest 90s
   - Chair/couch, decline angle hits upper chest (model chest line)
3. **Dumbbell Arnold Press / Band Press** - 3 x 10-12 | Rest 90s
4. **Dumbbell/Band Lateral Raises (drop set on last set)** - 3 x 12-15 | Rest 60s
5. **Bench Dips (between chairs) Weighted** - 3 x 10-15 | Rest 90s
6. **Band Chest Fly (or floor fly with dumbbells)** - 2 x 15 | Rest 60s

### PULL B - Back / Biceps (Thickness)
1. **Chin-ups (palms facing you)** - 5 x AMRAP | Rest 120s
2. **Single-Arm Dumbbell/Backpack Rows (lean on chair)** - 4 x 10-12 / arm | Rest 90s
   - Pull to hip, squeeze 1 sec.
3. **Pull-ups - Close Grip or Commando** - 3 x 6-12 | Rest 90s
4. **Reverse Fly (bent over, light DBs/bands)** - 3 x 15-20 | Rest 60s
5. **Hammer Curls** - 3 x 10-12 | Rest 60s
6. **Band Straight-Arm Pulldown / Superman Hold** - 2 x 15 / 30s hold

### LEGS B + CONDITIONING (Cut + Definition)
1. **Pistol Squat Progression OR Shrimp Squat** - 4 x 6-10 / leg | Rest 90s
   - Can't pistol? Do assisted with doorframe.
2. **Walking Lunges (backpack)** - 3 x 20 steps | Rest 90s
3. **Glute Bridges Single Leg** - 3 x 12-15 / leg | Rest 60s
4. **Calf Raises (on step, weighted)** - 4 x 15-25 | Rest 60s
5. **CONDITIONING - Pick ONE (12-15 min):**
   - Option A: HIIT - 30s sprint in place/high knees, 30s rest x 10
   - Option B: Burpees - 5 x 10 as fast as possible
   - Option C: Jump Rope 12 min

### SUNDAY - ACTIVE REST
- 8-12k steps (walk, don't run)
- Stretch 10 min: couch stretch, pigeon, doorway chest stretch
- 100 pushups spread through day (optional pump work)

## 4. PROGRESSION SYSTEM (EVERY WEEK)

Don't guess. Follow this:

**Week 1-2:** Learn form, find weight where last 2 reps are hard. Film yourself side-on.
**Week 3-4:** Add +1 rep to every set vs last week. If you hit top of rep range on all sets, add weight next week.
**Week 5-6:** Add weight: +2kg backpack, thicker band, or +1 set.
**Week 7:** Deload - cut volume by 50%, keep intensity. Let joints recover.
**Week 8-12:** Repeat cycle. You should be 20-30% stronger than week 1.

**When you plateau on pull-ups/pushups:**
- Day 1: Normal reps
- Day 2: Add weight (backpack) for 5-8 reps
- Negatives and holds: 3 x 5 sec hold at top

**Rep Ranges:**
- Strength/Size: 6-12 reps (heavy)
- Definition/Shoulders: 12-20 reps (lighter, strict)

## 5. ABS ARE NOT 1000 CRUNCHES

You need TWO things:
1. Low body fat (nutrition)
2. 3x/week direct work (already programmed)

For visible 4-6 pack, add 5 min at end of PUSH or PULL days:
- Hanging Leg Raise: 3x10-15
- Ab Wheel (with towel on smooth floor if no wheel): 3x8-12
- Cable Crunch substitute (band crunch kneeling): 3x15

Train abs like any muscle: weighted, progressive.

---

## 6. CARDIO & STEPS

Model physique = lean. You don't need hours of running (kills muscle).

- **Daily:** 8,000-12,000 steps. Track with phone. This burns fat without hunger spike.
- **2-3x/week:** 12 min HIIT (as in LEGS B) OR 20 min jump rope.
- Do cardio AFTER weights or on separate morning. Never before pull-ups.

If you're skinny trying to gain: skip HIIT, keep steps at 7k.
If you're 15%+ BF trying to cut: keep HIIT 3x + 10k steps.

---

## 7. TRACKING (Mandatory)

Weigh yourself Mon/Thu morning after toilet, before eating. Average weekly.

- Losing >0.7kg/week? Eat 200 cal more (you're losing muscle).
- Not losing weight for 2 weeks on cut? Cut 200 cal or add 2k steps.
- Photos: Front/side/back every 2 weeks, same light. Weight lies, photos don't.

Use `TRACKER.csv` in this repo.

## 8. TIMELINE - WHAT TO EXPECT

- **Weeks 1-4:** Neural adaptation, pump, posture better. -1 to -2kg fat if in deficit.
- **Weeks 4-8:** Shoulders/chest start to pop, veins in arms, top 2 abs in good light.
- **Weeks 8-12:** Real change. Clothes fit different. 4-pack visible if you were ~15% BF at start.
- **12-16 weeks:** Model territory if you were consistent on diet. 10-13% BF is achievable from 18%.

If you start skinny-fat: Bulk first (+200 cal) for 8 weeks, then cut.

## 9. COMMON BS TO AVOID

- No need for supplements except: Whey (if protein low), Creatine 5g/day (cheap, works), Vitamin D if no sun.
- No "fat burner" tea. No 6-hour workouts.
- No need to train abs daily.
- No starvation: <1500 cal will wreck hormones.
- Sleep 7.5+ hours or forget it. Muscle grows at night.
