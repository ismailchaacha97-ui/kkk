Install on MT4

  1. Download 3_Tier_London_Breakout_V3.3_BrokerTime.mq4
  2. Copy it into MQL4/Indicators (File → Open Data Folder)
  3. Restart MetaTrader or refresh Navigator, then drop it on a chart
  4. Leave AutoAdjustToBrokerTime = true. Set TimesAreSpecifiedIn to London, GMT, GMT+2, or Broker
  5. Offset is read from the server via TimeCurrent() − TimeGMT() unless you override BrokerGMTOffsetHours
